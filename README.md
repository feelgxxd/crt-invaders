# CRT Invaders

A small Space Invaders–inspired arcade game with a CRT-style visual aesthetic.
This project focuses on recreating the feel of classic arcade games while applying clean structure and modern JavaScript practices.

## 🎮 Overview

CRT Invaders is a lightweight browser-based game inspired by classic Space Invaders.

The goal of the project was to:
- Build a complete, playable game loop
- Apply a retro CRT visual effect
- Keep the codebase simple, readable, and extendable

## ✨ Features

- Classic arcade-style gameplay
- CRT-inspired visual effects
- Simple enemy behavior
- Score tracking and restart flow

## Controls

- **A / S** - Move
- **Shift** - Shoot

## 🤔 Why I Built This

I built this project to explore how much character and clarity can be achieved with simple mechanics and a strong visual identity.
It was also a way to practice finishing and polishing a small project rather than expanding scope indefinitely.
